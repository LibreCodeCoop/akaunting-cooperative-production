# Native module packaging decision

A separately versioned Akaunting module is the target, instead of converting
the legacy Symfony main branch or embedding incompatible Symfony dependencies.
Use the Akaunting module loader and `Modules\\CooperativeProduction` PSR-4
namespace. A single portable economic kernel is copied from the approved port;
future changes must be reconciled with the legacy reference, not fork policy.

The first native foundation is intentionally read-only. The server-resolved
company context and permission checks must be proven against a real test
database before exposing any preview route. Kimai absence must not create
tombstones except after a complete coherent authoritative reconciliation.

Historical import must preserve original revision, source ID, competence,
digest and uncertain publication state. Neither uninstall nor rollback can
delete accounting journals. No portal or Nextcloud-specific API belongs here.
